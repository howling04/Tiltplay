# 无板自测（不接板子验证 UE 侧）

用途：在没有板子、没有网关的情况下，确认 **UE + 插件 + 7001 + 设备 ID** 这一侧是对的。

## 怎么跑

1. 先启动 UE（或明天那份 exe），进到有角色的场景。
2. 双击 `START_NO_BOARD.cmd`，或手动执行：
   ```
   python replay_to_ue.py sample_input_40s.jsonl 7001 60
   ```
3. 约 40 秒内应按这个顺序变化：

| 时间 | 数据来源 | 角色应该 |
|---|---|---|
| 0–5 s | 平放 | 完全不动（`move`≈0） |
| 5–15 s | 前倾到 −46° | 持续前进 |
| 15–25 s | 回到平放 | 停止（中间有几段停在 +4°，属真实录制，不是 bug） |
| 25–35 s | 右倾到 +39° | 向右走 |
| 35–40 s | 回平 | 停 |

## 这份数据是什么

`sample_input_40s.jsonl` 是 **2026-11-25 那次 40 秒真实复测**的网关输出（2393 帧、60 Hz），原样保存，没有改过。里面包含真实的手抖、零点漂移和未回中的那几段，所以看起来不会像"动画一样完美"——这是故意的，用来判断 D 那边是否和我们的观感一致。

## 判读

- 角色完全不动、日志 `recv` 一直为 0：UE 没监听 7001，或端口被占。
- `recv` 涨但 `valid=0`：`TiltDump` 看 `age` 和 `device`；设备 ID 不匹配最常见。
- 方向反了（前倾后退）：这份数据是"前端下压=前进"；反了说明你的玩法层把 `Move.X` 用反了，不是插件问题。
- 只用这一次回放就能判断"我这边的接收是否正常"，剩下的交给真板子。
