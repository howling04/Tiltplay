# TiltPlayInput 插件接入说明

插件提供**一层**东西：把板子的倾斜变成每一帧的 `move`（-1…+1，X=前后、Y=左右），以及回中、跳跃、上下步这几类事件。它**不做**移动手感、不做角色、不做关卡——这些是 D 的玩法层，插件只给数据。

---

## 1. 前提

- UE **5.8.4**（插件按这个版本编译验证；其他 5.x 没验）
- 工程必须是**能编 C++ 的工程**（有 `Source/` 和自己的模块）。纯蓝图工程挂源码插件要先把工程转成 C++。
- VS2022 + UE 的 C++ 工具链（能正常 Build 工程即可）

---

## 2. 装进来（5 步）

1. 把 `TiltPlayInput` 整个目录拷到**你的工程**根目录下的 `Plugins\TiltPlayInput\`
   （最终路径：`<你的工程>\Plugins\TiltPlayInput\TiltPlayInput.uplugin`）。
2. 启用插件，两种方式任选：
   - 编辑器里：`Edit → Plugins`，搜 `TiltPlay Input`，勾选，重启；
   - 或直接改 `.uproject`，在 `"Plugins": [` 里加一条：
     ```json
     { "Name": "TiltPlayInput", "Enabled": true },
     ```
3. 右键 `.uproject` → `Generate Visual Studio project files`。
4. 编译工程（IDE 里 Build，或命令行 `Build.bat <你的工程>Editor Win64 Development -Project="...\\xxx.uproject"`）。
5. 启动，日志里应出现两行特征：
   - `LogPluginManager: Mounting Project plugin TiltPlayInput`
   - 每秒一行 `LogTiltPlayInput: [TiltPlay] fps=… seq=… valid=… move=(…)`

**不需要往场景里放任何 Actor。** 子系统是 `UGameInstanceSubsystem`，GameInstance 一起来就自动创建并开始监听 7001。

---

## 3. 取数据（C++）

```cpp
#include "InputServiceSubsystem.h"   // 插件 Public 头，加依赖后可直接 include

// 每帧 Tick 里：
if (UInputServiceSubsystem* Svc = GetGameInstance()->GetSubsystem<UInputServiceSubsystem>())
{
    FVector2D Move;
    if (Svc->GetTiltInput(Svc->GetDeviceId(), Move))   // false = 这一帧不能驱动
    {
        AddMovementInput(GetActorForwardVector(), Move.X);
        AddMovementInput(GetActorRightVector(),   Move.Y);
    }
    else
    {
        // 失联/失效：必须停控，否则会按最后一帧一直走
        GetCharacterMovement()->StopMovementImmediately();
    }
}
```

`GetTiltInput` 返回 false 的三种情况：没数据、数据 stale（>250 ms）、网关判定无效（含未回中）。**这三种在玩法上都应该等价于"停"**，不要只处理其中一种。

想省事也可以直接 `GetLocalTiltInput(Move)`，等价于用本机设备 ID 取。

---

## 4. 取数据（蓝图）

- 节点：`Get Game Instance Subsystem`，Subsystem Class 选 `Tilt Input Service`（类名 `UInputServiceSubsystem`）。
- 每帧用 `Get Local Tilt Input` → 返回 bool + Move（`FVector2D`）。false 就停。
- 或者绑事件：`On Input Updated (DeviceId, Move, bValid)`、`On Device State Changed (DeviceId, bValid, Reason)`、`On Recenter Result (bOk, Code)`、`On Vertical Step (DeviceId, Direction, Token)`。这四个都是 `BlueprintAssignable`。

注意：蓝图里广播发生在**游戏线程的 Tick**，可以直接在里面改角色状态；别在里面做重活。

---

## 5. 回中（R 键）

`RequestRecenter()`（C++）或 `Request Recenter`（蓝图）→ 往 `127.0.0.1:7002` 发控制包，网关做完回 `control_ack`，结果通过 `OnRecenterResult` 给出 `CENTERED / NOT_STILL / STALE`。

**当前限制（必须知道）**：
- **没有屏幕回执**。按 R 成功/被拒，界面上什么都不显示；我自己绑的 R 键只调 `RequestRecenter`。
- **板子必须平放（±10° 内）**，否则网关直接拒（`NOT_STILL`），且不会改零点。
- 每按一次 R，如果网关回 `control_ack`，插件目前会把它当"非 input 包"计入 `RejectedFrames`。**这是已知缺陷，不影响移动，但会让 reject 计数虚高**，看日志时别误判成链路坏了。

## 6. 参数（默认值都对，除非端口冲突否则别改）

| 属性 | 默认 | 说明 |
|---|---|---|
| `ListenPort` | 7001 | 收 input 帧的端口；必须和 `02_gateway` 的 `udp.port` 一致 |
| `ControlPort` | 7002 | 回中控制口；必须和 `gateway/config/bridge.json` 的 `udp.control_port` 一致 |
| `StaleSeconds` | 0.25 | 超过就判 stale（B 的冻结口径） |
| `FallbackDeviceId` | `nano-a1b2c3d4e5f6` | **白名单**。换成你板子的 ID，否则帧被当错误设备丢掉 |
| `RecenterTimeoutSeconds` / `RecenterRetries` | 0.3 / 2 | 回中等待与重试 |
| `bLogSummary` | true | 每秒一行统计，排障就靠它 |
| `bShowDebugOverlay` | true | 屏幕角上的调试信息 |

**端口冲突**：如果你的工程里已经有别的东西占 7001/7002（例如另一个 PIE 客户端、或上次没退干净的进程），改插件这两个属性，同时把 `bridge.json` 里的 `udp.port` / `udp.control_port` 改成一样的值——两边必须成对改。

**PIE 多开**：一个 GameInstance 一个子系统，两个客户端会抢同一个 7001，第二个绑不上。演示只开一个客户端；要多开得给每个客户端配不同端口（插件参数是类默认值，PIE 下不好改，建议演示时单开）。

---

## 7. 排障

| 现象 | 先看哪里 |
|---|---|
| 日志没有 `Mounting Project plugin TiltPlayInput` | 插件没启用 / 目录层级不对（必须是 `Plugins\TiltPlayInput\TiltPlayInput.uplugin`） |
| 有插件日志但 `recv=0` | 网关没在发：看网关控制台有没有"回中成功，开始输出"；或先跑 `04_无板自测` 排除 UE 侧问题 |
| `recv` 在涨但 `valid=0` | `TiltDump` 看 `age`；age 大 → 网关没发/发错端口；age 小但 valid=0 → 没回中或设备 ID 不匹配 |
| `reject` 一直涨 | 端口上有别的进程在发非 schema=2 的包；或者你按了 R（见 §5） |
| 角色自己走不停 | 没处理 `GetTiltInput` 返回 false 的分支 |

一条命令验一帧：控制台敲 `TiltDump`，打 `device / seq / move / angles / valid / stale / age / recv / reject`。

---

## 8. 打包时

插件是 `Runtime` 模块，`Enabled` 后打包会自动带上，不需要额外配置。打包版日志在 `Saved\Logs\`，同样用 `LogTiltPlayInput` 过滤。

插件里唯一写死的东西是 `FallbackDeviceId` 的默认值；如果板子 ID 会变，改这个默认值，或在 GameInstance 初始化后用 `GetTiltInput(DeviceId)` 显式传 ID。
