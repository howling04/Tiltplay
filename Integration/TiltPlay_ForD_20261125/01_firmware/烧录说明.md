# 固件烧录（USB_Live.ino）

## 这版固件做什么

板子在 USB 模式下每秒约 104 次往串口吐一行 JSON，`schema=2`，带 `acc_mps2`、`gyro_rps`、`button`、`seq/sample_seq/t_us`，并响应主机的 `cmd`（`ping` 探测、`recenter` 置零、`cfg` 配置）。

USB 口朝操作者、元件面朝上平放 = 基准姿态。前端（金属罩/点阵那头）向下压 = 前倾。

## 烧录步骤

1. 装 Arduino IDE 2.x，开发板管理器里装 **Arduino Mbed OS RP2040 Boards**。
2. 开发板选 **Arduino Nano RP2040 Connect**，端口选设备管理器里新出现的 COM 口。
3. 打开 `USB_Live.ino`，直接 Upload。
4. 烧完**关掉串口监视器**——它会占住 COM 口，网关就打不开了。

## 烧完怎么确认板子活着

串口监视器设 **921600**，应看到连续的行：

```json
{"channel":"raw","message":{"schema":2,"device_id":"nano-a1b2c3d4e5f6", ...}}
{"channel":"status","message":{...,"online":true,...}}
```

- 只有 `status` 没有 `raw`：板子没在采数据，重烧一次。
- 一行都不出：先确认波特率 921600，再换线（很多线只有供电没有数据）。
- `device_id` 必须是 `nano-a1b2c3d4e5f6`。**UE 插件里这个 ID 是白名单**，不一致时帧会被当成"错误设备"丢掉（`reject` 会涨）。
