# TiltPlay 给 D 的接入总览（2026-11-25）

## 上下手势启用修正版

本修正版已在设备配置开启 vertical_step_enabled，无须 D 再改开关。沿用 START_USB_LIVE.cmd COMx，停止旧网关后启动本包。mode 保持 tilt2，按钮跳跃仍关闭。此包为扩展演示配置，MVP 验收时将 vertical_step_enabled 改 false。

UE 插件默认自动消费上下事件：D 须绑定 OnVerticalStep，Direction=+1 调用一次 Q 对应上升逻辑，-1 调用一次 E 对应下降逻辑。不需要玩家按键。不要同时轮询 ConsumeVerticalStep，除非先关闭 bAutoConsumeVerticalStep。仅有插件不能替 D 的游戏蓝图自动接线，本包不含 D 工程。

先按原流程平放静置回中，valid=true 后拿起稳定至少约250ms，再做相对地面竖直的短促上/下推。识别阈值仍为待真板验证的原型，一次动作只能产生一次方向事件，游戏档位由 D 维护。

排错顺序：input_udp.jsonl 有没有 vertical_step 字段 → 有没有非null事件 → UE日志有没有 vertical_step 消费 → D的OnVerticalStep有没有执行。字段存在但一直null时，回传raw.jsonl及input_udp.jsonl，不要先放宽200ms年龄限制。附带40秒回放没有上下事件，不能据此测试上下手势。

这份包解决一件事：**让 D 不依赖我们的机器、不接板子也能先把 UE 侧跑通，接上板子就能出动作。**

包内分三块：固件、网关（USB 直连）、UE 插件。三者是独立的三段，任何一段坏了都能单独定位，不会一起沉默。

## 一、链路长什么样

```
Nano RP2040（USB_Live 固件）
   │  USB CDC，921600，每行一个 JSON（schema=2，约 104 Hz）
   ▼
record_live.py（网关 + 录制）
   │  校验：会话/序号/探测/新鲜度/回中门控，融合成角度，映射成 move
   │  UDP 127.0.0.1:7001，60 Hz
   ▼
UE（TiltPlayInput 插件）
   │  UInputServiceSubsystem 收 7001，逐帧判定 valid/stale
   ▼
角色移动（D 的玩法层）
```

反向只有一条：UE 按 R（或蓝图调 `RequestRecenter`）→ 往 **7002** 发 `type=control, op=recenter` → 网关回 `control_ack`。

## 二、最快路径（20 分钟）

1. **不接板子，先验 UE 侧**：打开 UE（或插件装好后跑起来），执行
   `python 04_无板自测\replay_to_ue.py 04_无板自测\sample_input_40s.jsonl 7001 60`
   → 角色应在前 5 秒不动，接着向前走，中段回平，再向右走。
   这一步能跑通，说明 UE、插件、7001 端口、设备 ID 全都对。
2. **接板子**：烧 `01_firmware\USB_Live.ino`（见该目录说明），记下串口号（例如 COM7）。
3. **起网关**：`02_gateway\START_USB_LIVE.cmd COM7`
   → 先要求你把板子平放，自动回中，然后开始 60 Hz 输出给 7001。

## 三、UE 侧两种接法（选一种）

**A. 用插件（推荐，能改玩法）** —— `03_ue_plugin\TiltPlayInput\`
把它拷进你自己工程的 `Plugins/`，启用后编译一次。之后任何 Character 里都能取到 move。
详细步骤、C++/蓝图写法、参数含义见 `03_ue_plugin\接入说明.md`。

**B. 用我们打包好的 exe（不能改）** —— 明天单独发。
原因：exe 整包 581 MB（去掉调试符号后），微信传不了，只能网盘/U 盘；而且它里面的参数是写死的（设备 ID、手感系数），改不了。今天这个包不含 exe，先用 A 方式把工程跑通，明天拿到 exe 直接双击也能演示。

## 六、判断"成功了没有"

| 位置 | 应该看到 |
|---|---|
| `CHECK_ENV.cmd` | Python 版本、`serial`/`paho` 可导入、7001/7002 未被占用 |
| 网关控制台 | `准备中…` → `平放检查通过` → `回中成功，开始输出到 127.0.0.1:7001` |
| 网关每 5 秒 | `valid≈2000/2000`，`move` 随姿态变化 |
| UE 日志 / TiltDump | `recv` 每秒 +60 左右，`reject=0`，`valid=1`，`move` 与姿态一致 |
| 角色 | 前倾=前进；平放=停；撤回平放立刻停（≤300 ms） |

UE 里验一帧最快的方法：控制台敲 `TiltDump`，会打出 seq / move / angles / valid / age / recv / reject。

## 七、必须知道的三个限制（详见 05）

1. **按 R 没有任何回执**。按下去成功也好、被门控拒了也好，屏幕上都不显示。先平放再按，用 `TiltDump` 或网关日志确认 `CENTERED`。
2. **手上拿着板子按 R 一定不生效**（这是设计）：倾斜超过 ±10° 网关会拒，日志写 `recenter_not_level`。
3. **默认双轴**。前后 + 左右都输出；只要前后就加 `--single-axis`。
